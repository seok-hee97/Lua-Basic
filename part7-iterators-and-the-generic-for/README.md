# 7 - Iterators and the Generic For

An iterator is any construction that lets you iterate over the
elements of a collection. In Lua, iterators are typically represented
as functions: each call returns the next element, or `nil` to signal
the end of the iteration. The generic `for` statement is built on top
of this convention.

# 2 - Types and Values

Lua is a dynamically typed language. There are no type definitions in
the language; each value carries its own type. There are eight basic
types in Lua: *nil*, *boolean*, *number*, *string*, *userdata*,
*function*, *thread*, and *table*. The function `type` returns the
type name of a given value.
